- Stop works while a worker is still launching, and no worker starts after you stop it. A failed worktree setup now shows its cause within seconds instead of leaving the dispatch queued.
- Worker setup is batched, so dispatch to first output dropped from about 12.1 to 9.8 seconds on the speed fixture. Workers also resume by themselves when a usage window resets.
- The server stays responsive under load. The worst event-loop stall on the test setup went from 567 ms to about 110 ms, with no wedges.
- Agents spend fewer tokens per turn. Built-in tool definitions load on demand (the default tool list went from about 33k to 13.4k tokens), and prompt prefixes stay warm for the session.
- Typing in a terminal echoes immediately.
- Codex app chats show only your own words. o8's instructions stay out of the visible message.
- Unsent steering drafts survive a reload and stay with their session.
- Merge preview lists every gate that would block the merge, with the action that clears each one.
- Idle memory is bounded. Transcript caches keep small summaries instead of whole histories: in a 96-session fixture, the two server processes went from 1,143 MB to 341 MB after activity.
- Background tabs and hidden windows no longer repaint unchanged transcripts, and they catch up as soon as you return.
- GitHub lists keep their cached data when a refresh comes back malformed. Pull request checks show neutral and skipped results as neutral, not as failures.
- Send Feedback is in the Help menu.
- Compact chat overlays have a readable backing, and sidebar popovers close with their column.
- Experimental: o8 next, a native GPUI client (transcript, diff and review, pane grid, terminal, composer and app shell), and o8d, a Rust service for live events and reads. Both are opt-in; the app you install is unchanged.
- Thanks to the outside contributors whose pull requests are in this release.
