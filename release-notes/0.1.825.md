- With the app open and nothing running, the server now rests. On our own install its memory at rest went from 1.4 GB to about 290 MB, and its CPU from 18% of a core to between 1% and 5%.
- A window left in front with nothing happening sends no requests once it has loaded. It used to send about 120 a minute.
- The server keeps answering while macOS shows a file-access prompt for a repository in Documents, Desktop, Downloads or on an external drive. It used to stop until the prompt was answered.
- The server answers requests while its startup maintenance is still running, and startup no longer blocks for several seconds on a large event history.
- A worktree cleanup that cannot finish is tried again after a day. It used to be retried on every start, with its whole file list loaded into memory.
- `o8 workspace-cleanup stuck-purges` lists the cleanups that can never finish and abandons the ones you choose. It shows a dry run unless you add `--apply`, and it leaves the folders on disk.
- `o8 mission archive --acknowledge-missing-worktree` closes a mission whose worker session and worktree are already gone.
- The launcher sleeps until one of its processes needs it. It used to wake 40 times a second.
- An unchanged phone inbox is reused for up to 30 seconds. It used to be rebuilt on every sync.
- The ports list checks the listening addresses first and runs the full scan only when they change.
- A Rust library the app uses for cookies is updated for a published security advisory.
