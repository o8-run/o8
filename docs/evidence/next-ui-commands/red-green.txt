through crate::agent::o8_http::post_json. All classic emits remain intact.

All three o8:ui-command producers in agent/tools/o8_ui.rs use the relay:
  open: settings, mobile_qr, automations, browser (including normalized URL),
        inbox, prs, activity, review, o8md, workspace, files, terminal.
  set_setting: theme, surface, canvas_mode; preserve key and value.
  orchestrator_draft: preserve text; no send is added.
The ink page's first-stroke, strokes and disarm-request events are forwarded
from the shell listeners; their capture/stash/disarm work remains intact.
clear is forwarded where Rust emits it to the overlay.

Agent events deliberately outside this UI-command relay:
  o8:worker-status: worker status for the dock, not a navigation command.
  o8:agent-task-event: task progress/status for the dock and existing listeners.
  o8:agent-confirm: confirmation workflow with Tauri replies, not surface navigation.
  o8:agent-confirm-dismissed: settles that same confirmation workflow.
  o8:symon-machine: machine/session state notification.
  o8:realtime-status: voice presence for the dock, not a voice-toggle command.
  o8:edit-capture: webview request/reply protocol via agent_edit_capture_result.
  o8:edit-apply: webview request/reply protocol via agent_edit_apply_result.
  o8:edit-applied: dock undo feedback after an edit, not an edit command.
  o8:edit-revert-settled: dock undo outcome, not a UI navigation command.
  voice_settings surface: macOS opens the native voice settings window directly
    and returns before emitting o8:ui-command; this native path stays intact.
